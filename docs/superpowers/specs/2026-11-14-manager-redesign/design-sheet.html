Shared design sheet

Every screen (Orders, order panel, Warranty, Products, Configurator Studio, Settings, pop-ups) will be built from these same pieces, so the whole app looks and behaves the same. Same colours, same status chips and words, same fonts and sizes, same 36px controls, same cards, menus and pop-ups, in dark and light mode. The Refund pop-up is a real example with everything today's version has.
